# Faction token icons

The SVG icons in this directory are adapted from [game-icons.net](https://game-icons.net/) and the [official game-icons/icons repository](https://github.com/game-icons/icons).

Icons used: `leaf-swirl`, `wolf-head`, `stag-head`, `crystal-growth`, `snowflake-1`, `fire-punch`, `daemon-skull`, `battle-axe`, `horned-helm`, `burning-eye`, `queen-crown`, `star-swirl`, `crossed-swords`, `laurels`, and `hourglass`.

All selected icons are by Lorc and licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The local adaptations remove the background and use a monochrome mask so the application can apply faction colors.
